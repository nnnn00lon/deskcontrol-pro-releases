Quick setup

  1. Download and install DeskControl for Windows.
  2. Download and install DeskControl for Android.
  3. Put both devices on the same local network.
  4. Enter the one six-digit code shown by Windows.
  5. Done. Future connections are automatic.

Main features

  • The same dashboard layout on Windows and Android
  • 20 Windows-configured typed Quick Launch slots
  • Logical audio mappings, media controls, and live PC telemetry
  • Windows-configured weather plus power controls
  • Real-time configuration sync after secure pairing

Private by design

Control traffic stays on your local network. Owner pairing uses a one-time code, OPAQUE authentication, encrypted TLS transport, certificate binding, and replay protection. Android requests typed slot actions only; it never receives arbitrary shell access.

Troubleshooting

  • Keep the Windows dashboard open and both devices on the same Wi-Fi.
  • On first discovery, Android automatically asks for the six-digit code shown by Windows.
  • If automatic discovery is blocked by the router, use the manual-address fallback in Android connection settings.
  • Allow local-network access when Android or Windows asks.
  • Android may ask you to allow installation from the browser or file manager used to open the APK.
