# DeskControl Pro V5 — current truth

Certification timestamp: 2026-09-04 UTC.

`v5.0.0` remains rejected by the failed TABWEE T20 physical validation. Its unreachable pairing UI, clipped real-tablet layout, and incorrect companion-only Windows design are not accepted or rewritten as passing history.

Corrective release `v5.0.1` is public. Windows and Android now use the same compiled React dashboard composition. Windows is additionally the authoritative editor and secure backend for exactly 20 typed Quick Launch slots, weather, logical audio mappings, pairing, and persisted configuration. Android is read-only for configuration and receives live and reconnect updates after authenticated WSS connection.

The v5.0.1 artifacts passed the canonical source gate, signed builds, local Windows installation, GitHub publication, Cloudflare Pages update, independent public redownload of both artifacts, SHA256 comparison, installation from the public Windows download, installed authenticated/restart/MITM tests, and an actual packaged-Electron dashboard/editor/pairing viewport test. Android reports versionCode 6/versionName 5.0.1 and retains the expected production signer.

No total-completion or automatable-percentage claim is made. The release status is `AWAITING_HUMAN_PHYSICAL_GATE`.

Hotfix release `v5.0.3` (Windows-only) is now public and installed-public-validated. The v5.0.2 physical failure was root-caused: Windows startup could replace the safe React weather state with the NativeHost GET_WEATHER payload (which does not always carry `location`), throwing `Cannot read properties of undefined (reading 'city')` in WeatherPanel and blanking the dashboard; the UI also mismatched the backend `apparentTemperature` vs the expected `feelsLike`, and old/partial/incomplete state was rendered unguarded. Remediation: `shared/normalizeWeather` canonicalizes every payload shape (undefined/null, missing location, missing city, loading, unavailable, partial NativeHost result, old persisted state, valid); `WeatherPanel` renders only through the normalized contract with explicit Loading/Location-not-configured/Weather-unavailable guards and never throws React; `PanelErrorBoundary` wraps each panel so a non-critical panel cannot blank the dashboard. The v5.0.3 Windows installer SHA256 `A4CABDF2...` was published to GitHub as the `latest` release, downloaded back from the public release, hash-verified (GitHub asset digest confirms an exact match), installed from the public artifact, and the packaged Electron dashboard was confirmed rendering at 1280x800 (20 Quick-Launch tiles, 6 mixer strips, 5 presets, 5 power controls, no overflow, touch-target sizing) with the live update check returning "DeskControl Pro 5.0.3 is up to date" and the weather panel rendering its truthful fallback. No Android changes were made for v5.0.3 (Android remains at 5.0.2).

The remaining gate is the repeated physical TABWEE T20 test: automatic six-digit pairing after discovery, real WebView/system-bar fit, representative Windows-to-tablet configuration sync and actions, reconnect/certificate behavior, touch/haptics/rotation/Wi-Fi behavior, and Wake-on-LAN assessment. Firmware virtualization remains unavailable, so emulator investigation was not repeated.
